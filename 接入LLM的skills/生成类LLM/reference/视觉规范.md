# 视觉规范：坐标网格城市视图

目标：像"城市总平面图"，不像插画。所有元素都为**读懂结构**服务。

## 画布

| 常量 | 值 | 说明 |
|---|---|---|
| `CELL` | 128 | 单格边长（逻辑像素） |
| `GAP` | 9 | 格间距，用来放门/墙 |
| `SCALE` | 2 | 超采样倍数，最后 LANCZOS 缩回；**字号要乘 SCALE** |
| `PAD_L / PAD_T` | 88 / 246 | 左侧留给行号，顶部留给标题 + 列号 |
| `PAD_R / PAD_B` | 34 / 92 | 右侧留白 + 底部出处 |
| `LEGEND_W` | 452 | 右侧图例栏宽度 |
| 画布公式 | `W = PAD_L + 列*CELL + (列-1)*GAP + PAD_R + LEGEND_W`<br>`H = PAD_T + 行*CELL + (行-1)*GAP + PAD_B` | 按内容算，不要写死 2400×1620（地图会缩在左上角） |

## 元素画法（按 z 序）

1. **格线**：每格描 1px `#E4DED2`，让人一眼看出坐标格。
2. **墙**：相邻但未连线的两块之间，画浅色横杠，**两端各缩进 6px**（不缩进会顶到方块圆角）。
3. **门**：画在两块公共边的中点，宽度 `0.3 × CELL`；竖边上的门画成竖条，横边上的画成横条。
4. **区域块**：圆角矩形，道路圆角 8、其他 12；1px `rgba(0,0,0,0.11)` 描边；道路块中央写"路"，其他写名字。
5. **名字排版**：名字居中；有副标题时名字上移 12px，副标题 15px 放在 +21px 处；名字 >4 字自动降到 21px。
6. **坐标角标**：块左上角 `(x0+9, y0+7)`，15px，`rgba(0,0,0,0.33)`；2×2 追加 `·2×2`。
7. **`&` 框**：包住两块外扩 5px，圆角 16，2.4px 红线；徽章直径 26px，放在两块**共用边的中点**（水平对取两块的 x 均值，垂直对取 y 均值）。
8. **图例栏**：色块 34×34（圆角 9）+ 18px 标签；下面依次是门、墙、`&` 三个示意。
9. **本城要点**：图例下方 4–6 行 18px 灰字，写骨架、网格、区域数、各类数量。
10. **指北针**：右下角，实心三角 + "N"。

## 排版禁区

- 文字**不要**压在门的色条上（门画在 GAP 内，文字留内边距就够）。
- 坐标角标不要和长名字抢位置：名字 >5 字时优先缩字号。
- 图例栏不要用半透明底，直接画在画布底色上更干净。
- 道路格**不要**加虚线中线：会压住"路"字，看起来像删除线。
