# 校验清单：把规则变成断言

出图前逐条跑。左边是蓝图原话，右边是生成器里该写的断言。
只要有一条不通过，**不要出图**，先把布局改对。

## 一、结构类

| # | 规则原话 | 断言写法 |
|---|---|---|
| 1 | 网格基本单位 1×1 | 所有区域左上角为整数坐标，占地 ∈ {(1,1),(2,2)} |
| 2 | 居民区 / 位面传送门 / 宫殿 2×2 | `for n in nodes if n.w==2: assert n.h==2 and n.name in {居民区, 位面传送门, 宫殿}` |
| 3 | 区域不重叠 | 占用矩阵 `occ[x][y]` 写入前判空 |
| 4 | 2×2 四边不留碎格 | 2×2 外扩 1 格的环形区域里，不允许出现宽 1 的空格（会被当成路） |
| 4b | **不许出现 2×2 纯道路**（不符合人类审美） | 扫描所有 2×2 窗口，四格皆为路面即红灯。修法：把窗口里最靠几何中心的一格**删掉**（不新增区域类型），删后立刻 BFS 复检道路连通；逐格试，四格都不行则保留窗口并报错 |

## 二、相邻与门

| # | 规则原话 | 断言写法 |
|---|---|---|
| 5 | `-` 表示可达且必须区分可达/不可达 | 对每一对正交相邻的区域，要么在 `edges` 里（画门），要么在 `walls` 里（画墙），二者必居其一 |
| 6 | 每个区域至少与道路相邻且有一处门 | `len(adj_roads(n)) > 0`；`&` 对允许 `adj_roads(partner)` 非空 |
| 7 | `&` 必须相邻且合并 | 对每一对：`orthogonally_adjacent(a,b)` 为真，且二者之间有门 |
| 8 | 四组必邻对 | 公园&林地、教堂&墓地、冒险者协会&政府、魔法协会&科学协会，各恰好 1 组 |

## 三、数量与位置

| # | 规则原话 | 断言写法 |
|---|---|---|
| 9 | 居民区 2–3 | `2 <= count("居民区") <= 3` |
| 10 | 公园&墓地 1–2 | `1 <= count("公园") <= 2` 且 `count("墓地") == 1` |
| 11 | 酒馆 / 城市公园 / 市场 各 1–3 | 各自 `1 <= count <= 3` |
| 12 | 其余唯一 | `count(name) == 1` |
| 13 | 位面传送门在城心 | `manhattan(center(portal), center(map)) <= 1`（2×2 取几何中心） |
| 14 | 宫殿远离住宅、靠近公园 | `min_dist(palace, 住宅) >= 3` 且 `min_dist(palace, park) <= 2` |
| 15 | 家在某条路的末尾 | 家在的相邻道路格，其道路邻居数 == 1（端点） |
| 16 | 公园 / 教堂在路网末梢 | 相邻道路格的道路邻居数 <= 2 |
| 17 | 酒馆/市场/城市公园靠近住宅 | `min_dist(x, 住宅) <= 3` |
| 18 | 协会/政府/地标贴近中心 | `dist_center(x) <= 3` |

## 四、全局

| # | 检查 | 做法 |
|---|---|---|
| 19 | 全图连通 | 从任一节点 BFS（边 = `edges`），访问数 == 节点数 |
| 19b | 接路判定要允许串联 | 位面传送门（2×2）当路口，`reaches_road(idx)` 用 BFS 允许经 `road/core` 转发；孤立单格出图前 `prune_orphans()` 删掉，碎成两片则 `bridge_components()` 补一条 1 格宽小路 |
| 19c | **道路不许割裂：所有路面必须连成一张网** | 取 `road ∪ core` 的全部格做 BFS（2×2 展开成 4 格），连通块必须为 1；生成期用带权最短路补最短连接路（穿过已有路/传送门代价 0，新铺一格代价 1） |
| 20 | 道路自身连通 | 只保留 `kind=='road'` 的节点做一次 BFS |
| 21 | 无孤立区域 | 每个非道路区域的度数 ≥ 1 |
| 22 | 空地率可接受 | `空地 / 总格 < 45%`（超过说明该加支路或减网格） |
| 23 | **紧凑：中心区不许大片空格**（会造成割裂感） | 以几何中心为心、半径 2 的方框内，统计"挨着道路的空格"；`hole > 4` 视为割裂（细巷口允许 1–3 个）。修法：放置打分加 `occupied_neighbors(nd) * 1.3`，末尾 `fill_with_roads()` 伸 1 格短支路补洞（只用道路，且不得凑出 2×2 纯道路） |

## 典型红灯

```
✗ 墓地(8,7) 未接路          → 墓地靠教堂接路即可，校验函数没放行 & 搭档
✗ 不连通：路、路、酒馆、市场  → build_roads 里随机删了道路格
✗ 宫殿贴着传送门            → 宫殿打分函数漏了"离核心太近则否决"
```
